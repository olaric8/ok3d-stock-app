# Note on oauth2client
# --------------------
# The brief listed `oauth2client`, which was the standard Google auth helper for
# years. It is now deprecated and, more importantly, **gspread 6.x removed its
# oauth2client-based authorize() path entirely** -- passing oauth2client
# credentials to modern gspread raises. This app therefore authenticates with
# `google-auth` (the supported replacement, and the same service-account JSON
# file either way).
#
# oauth2client is deliberately NOT installed: keeping it would add a deprecated,
# unmaintained dependency that no code path touches. If you ever pin gspread<6,
# add `oauth2client>=4.1.3` back at that point.
# ---------------------------------------------------------------------------
